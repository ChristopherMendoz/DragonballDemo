DEL REQUEST AL RENDER

Cómo funciona Fetch

Cuatro pasos, desde que solicitas los personajes hasta que aparecen en pantalla.

✳
01↗

Hacer la petición

fetch(url) inicia un GET a la API y devuelve una promesa.

→
02⇣

Revisar la respuesta

Se comprueba response.ok y el estado HTTP antes de procesar los datos.

→
03{ }

Convertir a JSON

response.json() transforma la respuesta en un objeto de JavaScript.

→
04▤

Mostrar los datos

Leemos name, race e image para construir cada tarjeta.

A

Con async / await

Se lee como una secuencia de pasos.

MODERNO
async function obtenerPersonajes() {
  const respuesta = await fetch(url);
  if (!respuesta.ok) throw new Error(respuesta.status);
  const datos = await respuesta.json();
  pintarPersonajes(datos.items);
}
B

Con promesas

Encadena el éxito y captura errores.

.THEN / .CATCH
fetch(url)
  .then(respuesta => {
    if (!respuesta.ok) throw new Error(respuesta.status);
    return respuesta.json();
  })
  .then(datos => pintarPersonajes(datos.items))
  .catch(error => mostrarError(error));
01 / RESPUESTA

Una petición exitosa devuelve información JSON. En esta API, la lista viene en items y cada personaje contiene campos como nombre, raza, imagen y afiliación.
